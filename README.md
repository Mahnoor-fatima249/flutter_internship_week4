# Flutter Internship Week 4

## API Integration & Mini Project

### Objective
Learn API integration through a Weather App mini project.

### Tasks Completed
- Created a Weather App
- Fetches weather data from wttr.in (free API)
- Displays city name, temperature, weather condition
- Shows loading indicator
- Handles API errors gracefully
- Uses FutureBuilder for async operations

### Topics Covered
- HTTP Package
- API Integration
- JSON Parsing
- FutureBuilder
- Error Handling
