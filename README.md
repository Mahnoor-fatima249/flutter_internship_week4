# Flutter Internship - Week 4: Weather App (API Integration)

This project is part of the Flutter Internship program, focusing on **API Integration**, **JSON Parsing**, asynchronous programming, and handling network requests in Flutter.

---

## 🚀 Features Implemented
* **Weather Forecast Screen:** A dedicated modern UI interface with a weather gradient background.
* **Live API Integration:** Fetches real-time weather data using the public `wttr.in` API.
* **Dynamic Data Display:** Accurately displays City Name, Temperature (°C), Weather Condition, Humidity, and Wind Speed.
* **Loading Indicator:** Shows a smooth circular progress indicator while fetching data from the server.
* **Graceful Error Handling:** Catches network failures and invalid city inputs, displaying helpful warning messages to the user.

---

## 🛠️ Tech Stack & Topics Covered
* **Framework:** Flutter (Dart)
* **Networking:** `http` package (^1.2.0)
* **Data Format:** JSON Parsing (`jsonDecode`)
* **State Management:** `setState` & Asynchronous Programming (`async/await`)

## ⚙️ How to Run the Project

1. Clone the repository:
```bash
git clone [https://github.com/Mahnoor-fatima249/flutter_internship_week4.git](https://github.com/Mahnoor-fatima249/flutter_internship_week4.git)

```


2. Navigate to the directory:
```bash
cd flutter_internship_week4

```


3. Get dependencies:
```bash
flutter pub get

```


4. Run the app:
```bash
flutter run

```
